## Git Commit Guidelines
Using conventional commits:
- `feat:` New gameplay, API, or database capabilities
- `fix:` Bug fixes, constraint patches, error handling
- `docs:` Documentation, schema diagrams, reports
- `test:` Database constraint tests, API tests, concurrency benchmarks
- `refactor:` Code improvements without feature changes
